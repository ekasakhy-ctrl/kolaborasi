Matematika

Dama Aji Kurniawan (18)

Tampilkan

X = Robot Mobil
Y = Disgrip

x + 2y = 200.000 .......pers 1
2x + y = 250.000 .......pers 2

eliminasi Y
(x + 2y) - (4x + 2y) = 200.000 - 500.000
-3x = -300.000
x = 300.000 / 3
x = 100.000

substitusi ke persamaan 2
X + 2y = 200.000
100.000 (1) + 2y = 200.000
2y = 200.000 - 100.000
2y = 200.000 / 2
y = 50.000


Keterangan : Jadi, harga 1 robot (X) yaitu 100.000 Dan harga 1 sound sistem (Y) 50.000

Eka Sakhy Yuliana (18)

Tampilkan
X = jam
Y = lampu

2x + 3y = 420.000 .......pers 1
4x + 5y = 780.000 .......pers 2

eliminasi Y
(10x + 15y) - (12x + 15y) = 2.100.000 - 2.340.000
-2x = -240.000
2x = 240.000 / 2
x = 120.000

substitusi Ke Persamaan 1
2x + 3y = 420.000
120.000(2) + 3y = 420.000
240.000 + 3y = 420.000
3y = 420.000 - 240.000
3y = 180.000 / 3
y = 60.000

Keterangan : Jadi harga 1 Jam (X) yaitu 120.000.Dan harga 1 Lampu (Y) yaitu 60.000.

Gifany Hasiolan (20)

Tampilkan
X = lampu
Y = Tempat sampah

3x + y = 520.000 .......pers 1
x + 2y = 590.000 .......pers 2

eliminasi Y
(6x + 2y) - (x + 2y) = 1.040.000 - 590.000
5x = 450.000
5x = 450.000 / 5
x = 90.000

Subtitusi ke persamaan 1
3x + y = 520.000
90.000(3) + y = 520.000
270.000 + y = 520.000
y = 520.000 - 270.000
y = 250.000

Keterangan : Jadi,harga 1 lampu (X) yaitu 90.000 Dan harga 1 Tempat Sampah (Y) yaitu 250.000
